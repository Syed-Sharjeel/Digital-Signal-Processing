# Digital Signal Processing (DSP) Code Labs

A collection of Digital Signal Processing (DSP) laboratory experiments, code implementations, and reports completed as part of the DSP course. This repository contains MATLAB programs, experiment reports, observations, and supporting resources for understanding the theoretical and practical aspects of Digital Signal Processing.

## 📖 Course Overview

Digital Signal Processing (DSP) is the study of analyzing, modifying, and synthesizing discrete-time signals using mathematical algorithms and digital systems. This repository provides hands-on implementations of the fundamental concepts taught in a typical undergraduate DSP laboratory.

## 🎯 Learning Outcomes

After completing these labs, students should be able to:

- Understand the sampling theorem and aliasing.
- Analyze quantization effects in digital systems.
- Perform discrete-time convolution and correlation.
- Compute and interpret the Discrete Fourier Transform.
- Analyze real-world audio signals in the frequency domain.
- Relate Laplace, CTFT, Z-Transform, and DTFT.
- Design FIR filters using windowing techniques.
- Design IIR filters using MATLAB's Filter Designer (FDA Tool).
- Apply DSP concepts to solve practical signal-processing problems.
